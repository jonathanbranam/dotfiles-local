Found reviewing 2cdf11d (dl-3c6e). local/bin/dotfiles-update runs plain 'rcup', which runs thoughtbot's hooks/post-up every time: 'vim -E -s +PlugUpgrade', 'vim -u ~/.vimrc.bundles +PlugUpdate +PlugClean! +qa', 'reset -Q'. In a launchd job with no tty that is slow, hits the network on every run, may hang on a full-screen vim, and PlugClean! deletes plugins. Use 'rcup -K' in the script (links only); plugin updates stay a manual 'rcup' or :PlugUpdate. Note it in the README Auto-update section. Also: local/bin/.gitignore is '*' with an allowlist; add '!dotfiles-update' there instead of relying on the force-add, so future edits aren't surprising.
